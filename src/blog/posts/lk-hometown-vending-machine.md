키오스크와 자판기를 하나로 합친 모델이에요. 큰 화면에 상품 사진과 설명을 띄워 믿고 살 수 있게 하고, 판매하지 않는 시간에는 매장 광고판이 됩니다.

## 어떤 점이 다른가요?

24인치 터치스크린으로 상품을 고르고, 장바구니에 여러 개를 담아 한 번에 결제합니다. 화면이 크다 보니 상품 사진과 상세 설명을 함께 보여줄 수 있어, 처음 보는 상품도 고르기 편해요.

## 기본 사양

| 항목 | 내용 |
| --- | --- |
| 모델 | HT-MTS-v01 |
| 크기 | 가로 955 × 높이 1,970 × 깊이 920mm |
| 화면 | 24인치 터치스크린, 동영상·광고 송출 |
| 판매 방식 | 스파이럴·푸쉬 트레이 6단 선반 기본 |
| 수납량 | 슬림캔 최대 300개, PET 음료 최대 240개 |
| 결제 | 신용카드, 삼성페이, 카카오페이, 제로페이 |
| 사용 온도 | 3~20℃ (실내 설치 기준) |
| 소비전력 | 364W |
| 확장 | 보조 밴딩머신 최대 2대 연동 |

## 광고는 어떻게 나가나요?

세로형(1080×1920) 영상을 준비해 주시면 판매가 없는 시간에 화면에 띄웁니다. 일시불과 할부 모두 3년간 자체 매장 광고를 송출할 수 있어요. 무상 A/S 기간에는 본사가 모집한 광고가 함께 나갈 수 있습니다.

## 재고와 매출은 어디서 보나요?

관리 프로그램과 앱을 무상으로 드립니다. 어떤 상품이 잘 팔리는지, 무엇이 떨어졌는지 매장에 가지 않아도 확인할 수 있어요. 외부 서버 접근을 차단해 판매 데이터를 안전하게 지킵니다.
